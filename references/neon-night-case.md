# Neon Night case

Developed collaboratively by Shepherdess and Tachikoma on 23 November 2026 while enlarging a 1536 × 1024 character reference sheet to 6144 × 4096.

The initial Lanczos enlargement retained the source but stayed soft. An anime-focused neural model sharpened contours while simplifying lacing, hardware, and leather reflections. A source-weighted gentler model preserved more existing detail.

Shepherdess proposed generative editing in tiles or sections. A close-up boot test produced detailed eyelets, laces, and material reflections. She then identified missing visible bracing above the main boot, establishing the need to review construction before surface finish.

The console graphics analogy is budget allocation: give one section the full rendering budget, retain overlap as guard bands, assemble the sections, and composite lettering as a separate overlay. A source crop of width w rendered at width W receives W/w output pixels per source pixel locally. Measure actual section sizes and sum generation work when comparing cost.

The reusable method includes semantic mapping, immutable coordinates, context references, explicit component invariants, native generative edits, construction review, bounded registration, feathered compositing, and separately protected typography. Preserve the plan and review records with the artifact.
