# Construction before polish

1. Match render and source at the same apparent size.
2. Trace current-image connections and attachment paths end to end.
3. Distinguish actual structure from decorative highlights or surface texture.
4. Check component counts, orientation, symmetry/asymmetry, occlusion and pose.
5. Check identity, expression, silhouette, coverage, colors and material continuity as applicable to the current image.
6. Check fine surface detail after construction passes.
7. Inspect again after registration and compositing.

Use the job's invariants for unchanged-source checks. Use the separate corrections list for explicitly requested design changes. Report deviations against the correct reference: original structure for enlargement, requested change for corrected regions.

If a requirement changes during a run, preserve prior outputs and mark affected records for re-preparation and review. Do not infer that an intervention caused an artifact without comparing the corresponding versions. Keep the reusable method free of any single image's content rules.

The optional case reference illustrates this review order. It supplies no default anatomy, equipment, colors or component constraints for other images.
